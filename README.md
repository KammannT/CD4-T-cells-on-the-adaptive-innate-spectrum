Information on CITE-seq and scTCR-seq data:
MAIT cells, T cells and NK cells were isolated from four healthy human peripheral blood donations and subjected to single cell sequencing of gene expression (GEX), surface epitome (ADT) and TCR information.
This repository contains code for the analysis of CD161+ CD56+ CD4+ T cells described in Kammann et al. 2025 (DOI: ).
Single cell sequencing data is available at Zenodo, DOI: 10.5281/zenodo.14851876
